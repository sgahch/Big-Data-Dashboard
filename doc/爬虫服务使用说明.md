# 清风网爬虫服务使用说明（增强版 v2.0）

> **功能升级**：支持一次性爬取所有侧边栏菜单的内容，包括省管干部和其他干部的执纪审查、党纪政务处分等分类。

---

## 📋 功能特性

### ✅ 支持的分类

| 主分类 | 子分类 | 类型标识 | 说明 |
|--------|--------|---------|------|
| **省管干部** | 执纪审查 | `provincial_discipline` | 省级干部纪律审查案件 |
| **省管干部** | 党纪政务处分 | `provincial_punishment` | 省级干部处分决定 |
| **其他干部** | 执纪审查 | `other_discipline` | 其他干部纪律审查案件 |
| **其他干部** | 党纪政务处分 | `other_punishment` | 其他干部处分决定 |

### ✅ 数据字段

每条新闻包含以下字段：

```json
{
  "title": "新闻标题",
  "summary": "新闻摘要",
  "date": "发布日期（YYYY-MM-DD）",
  "url": "原文链接",
  "source": "清风网",
  "category": "主分类（如：省管干部）",
  "subcategory": "子分类（如：执纪审查）",
  "type": "类型标识（如：provincial_discipline）"
}
```

## 📡 API接口说明

### 1. 获取所有新闻

**接口地址**：`GET /api/news`

**查询参数**：

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `category` | String | 否 | 主分类过滤 | `省管干部` |
| `subcategory` | String | 否 | 子分类过滤 | `执纪审查` |
| `limit` | Integer | 否 | 返回数量限制（默认50） | `10` |

**请求示例**：

```bash
# 获取所有新闻
curl http://localhost:5000/api/news

# 获取省管干部的所有新闻
curl http://localhost:5000/api/news?category=省管干部

# 获取省管干部的执纪审查新闻
curl "http://localhost:5000/api/news?category=省管干部&subcategory=执纪审查"

# 获取最新10条新闻
curl http://localhost:5000/api/news?limit=10
```

**响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "title": "陕西中医药大学副校长缪峰接受纪律审查和监察调查",
      "summary": "陕西中医药大学副校长缪峰涉嫌严重违纪违法，目前正接受陕西省纪委监委纪律审查和监察调查",
```

```javascript
async function getStatsByCategory() {
    const response = await fetch('http://localhost:5000/api/news');
    const result = await response.json();
    
    const stats = {};
    result.data.forEach(item => {
        const key = `${item.category}-${item.subcategory}`;

    });
```

## ⚠️ 注意事项

### 1. 爬虫频率限制

- 爬虫在请求不同分类时会自动添加 **0.5秒延迟**，避免请求过快
- 建议不要频繁调用API，可以设置缓存机制

### 2. 数据更新频率

- 清风网的数据更新频率不固定
- 建议每 **5-10分钟** 调用一次API获取最新数据

### 3. 错误处理

- 如果爬虫失败，API会自动返回Mock数据
- 生产环境建议添加重试机制

## 🐛 故障排查

### 问题1：服务无法启动

**检查步骤**：
1. 确认Python已安装：`python --version`
2. 确认依赖已安装：`pip install -r requirements.txt`
3. 检查端口5000是否被占用：`netstat -ano | findstr :5000`

### 问题2：API返回Mock数据

**可能原因**：
- 清风网页面结构发生变化
- 网络连接问题
- CSS选择器失效

**解决方案**：
1. 查看服务器日志，确认错误信息
2. 访问 https://www.qinfeng.gov.cn/scdc.htm 确认页面是否正常
3. 根据实际页面结构调整 `crawler_server.py` 中的选择器

### 问题3：部分分类无数据

**检查步骤**：
1. 访问 `/api/categories` 确认分类配置
2. 查看服务器日志中的爬取信息
3. 手动访问清风网确认该分类是否有数据
