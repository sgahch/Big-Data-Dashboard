# Coze 智能体切换快速参考卡片

> **⏱️ 预计耗时：3分钟**  
> **📁 需要修改的文件：`index.html`**  
> **📍 修改位置：第 404-408 行**

---

## 🚀 快速切换（3步完成）

### 步骤1：获取新智能体信息

登录 [Coze控制台](https://www.coze.cn/)，获取：

```
✅ Bot ID:   从URL中复制（例如：7584642107525824539）
✅ API Key:  从"个人设置→API密钥"中生成
```

---

### 步骤2：修改配置

打开 `index.html`，找到第 **404-408 行**：

```javascript
// ========== API配置常量 ==========
const COZE_BOT_ID = "粘贴您的Bot ID";
const COZE_API_KEY = "粘贴您的API密钥";
const COZE_CHAT_URL = "https://api.coze.cn/open_api/v2/chat";  // 保持不变
const CRAWLER_API_URL = "http://localhost:5000/api/news";  // 保持不变
```

---

### 步骤3：测试验证

1. **保存文件** → 按 `Ctrl+S`
2. **刷新浏览器** → 按 `F5`
3. **测试对话** → 在AI助手中输入"你好"
4. **检查回复** → 确认AI正常响应

---

## 📋 配置检查清单

在切换智能体后，请逐项检查：

- [ ] Bot ID 已正确粘贴（纯数字，19位）
- [ ] API Key 已正确粘贴（以 `pat_` 开头）
- [ ] 浏览器已刷新（F5）
- [ ] AI助手能正常回复
- [ ] 浏览器Console无红色错误（F12查看）

## 🔍 常见错误速查

| 现象 | 原因 | 解决方案 |
|------|------|----------|
| 一直显示"正在查询知识库" | API配置错误 | 检查Bot ID和API Key |
| 提示"API密钥无效" | API Key错误 | 重新生成并粘贴API密钥 |
| 提示"智能体不存在" | Bot ID错误 | 检查Bot ID是否正确 |
| 回复"抱歉，我暂时无法回答" | Bot未正确配置 | 登录Coze检查Bot状态 |

## 💡 高级技巧

### 技巧1：使用配置模板快速切换

将 `bot_config_template.js` 的内容复制到 `index.html` 的配置区域，然后只需修改一行：

```javascript
const CURRENT_BOT = 'discipline_inspection';  // 切换到纪检监察助手
```

在 `index.html` 中注释保存旧配置：


## ⚠️ 注意事项

1. **API密钥安全**：
   - ❌ 不要将包含真实API密钥的代码提交到公开仓库
   - ✅ 使用环境变量或配置文件管理密钥

2. **Bot发布状态**：
   - 确保Bot已在Coze控制台中发布
   - 未发布的Bot无法通过API调用

3. **API调用限制**：
   - 免费版可能有调用频率限制
   - 如遇429错误，请等待1分钟后重试
