# 数据库迁移

执行数据库迁移操作。

```bash
# 创建迁移文件
python manage.py makemigrations

# 应用迁移
python manage.py migrate

# 查看迁移状态
python manage.py showmigrations
```

## 重置数据库（谨慎使用）

```bash
# 删除数据库文件（SQLite）
del db.sqlite3

# 删除迁移文件
del apps/*/migrations/*.py
del apps/*/migrations/__init__.py

# 重新创建
python manage.py makemigrations
python manage.py migrate
```
