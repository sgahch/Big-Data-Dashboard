# 智慧监督管理系统 - 功能清单

> 版本：v1.0
> 创建日期：2025-01-27

---

## 一、用户与权限管理

| 二级功能目录 | 三级功能目录 | 功能描述 |
|--------------|--------------|----------|
| **系统用户管理** | 用户增删改查 | 负责系统用户的增、删、改、查、禁用等操作 |
| | 用户禁用/启用 | 控制用户登录状态 |
| | 密码重置 | 管理员重置用户密码 |
| **角色管理** | 角色定义 | 定义系统角色（系统管理员、监督领导、普通监督员等） |
| | 角色权限分配 | 为角色分配菜单、按钮、数据范围权限 |
| | 角色增删改查 | 角色CRUD操作 |
| **权限配置** | 菜单权限 | 控制角色可见的菜单项 |
| | 按钮权限 | 控制角色可操作的按钮 |
| | 数据范围权限 | 按部门/监督维度控制数据可见性 |
| **操作日志** | 日志记录 | 记录用户关键操作（登录、修改配置、处理任务） |
| | 日志查询 | 按时间、用户、操作类型查询 |
| | 日志导出 | 导出日志用于审计 |

## 二、数据源管理

| 二级功能目录 | 三级功能目录 | 功能描述 |
|--------------|--------------|----------|
| **数据源配置** | 新增数据源 | 增加需要爬取的网站地址（URL） |
| | 编辑数据源 | 修改已配置的数据源信息 |
| | 删除数据源 | 删除不再需要的数据源 |
| | 数据源测试 | 测试数据源连通性和可爬取性 |
| **数据源分类** | 网站类型管理 | 区分校园主站、各学院网站等 |
| | 部门网站配置 | 按部门管理数据源 |

## 三、爬虫调度管理

| 二级功能目录 | 三级功能目录 | 功能描述 |
|--------------|--------------|----------|
| **任务配置** | 新增爬虫任务 | 创建爬虫任务并关联数据源 |
| | 任务调度设置 | 设置执行周期（每天、每周）和触发条件 |
| | 任务启停控制 | 手动启动/停止爬虫任务 |
| | 任务优先级 | 设置不同任务的执行优先级 |
| **运行监控** | 任务状态监控 | 监控爬虫任务运行状态 |
| | 任务执行日志 | 记录每次爬取的结果和耗时 |
| | 异常告警 | 任务失败时发送告警通知 |
| **系统监控** | 服务器监控 | 监控CPU、内存、磁盘使用率 |
| | API健康检查 | 监控API接口可用性 |

## 四、监督事项管理

| 二级功能目录 | 三级功能目录 | 功能描述 |
|--------------|--------------|----------|
| **监督清单维护** | 清单增删改查 | 对核心监督事项进行增、删、改、查管理 |

| **监督分类管理** | 一级分类 | 建立监督事项一级分类（如：主体责任、监督责任等） |
| | 二级分类 | 建立二级细分分类 |

## 五、关键词库管理

| 二级功能目录 | 三级功能目录 | 功能描述 |
|--------------|--------------|----------|
| **关键词配置** | 核心关键词 | 为每个监督事项配置核心关键词 |
| | 近义词管理 | 配置关键词的近义词扩展 |

| | 词库分类 | 按监督事项分类管理关键词 |

## 六、智能分析引擎

| 二级功能目录 | 三级功能目录 | 功能描述 |
|--------------|--------------|----------|
| **语义分析** | NLP语义理解 | 运用自然语言处理技术，理解文章语义 |
| | 超越关键词匹配 | 基于语义分析，提高识别准确率 |
| **自动分类** | 智能分类 | 根据分析结果，自动将文章分类到对应监督事项 |
| | 自动打标 | 为文章打上相关标签 |
| | 置信度计算 | 计算分类结果的置信度 |
| **智能识别** | 监督事项匹配 | 自动识别文章关联的监督事项 |
| | 关键词高亮 | 在展示时高亮触发规则的关键词 |

---

## 七、数据采集与处理

| 二级功能目录 | 三级功能目录 | 功能描述 |
|--------------|--------------|----------|
| **网络爬虫引擎** | 定时爬取 | 根据预设周期，自动从数据源爬取最新文章 |
| | 多数据源爬取 | 支持多个网站并行爬取 |
| | 增量爬取 | 仅爬取新增或更新的内容 |
| **内容提取** | HTML解析 | 精准解析网页结构，提取标题、正文、发布时间、发布部门、来源链接 |
| | 图片提取 | 提取文章中的图片资源 |
| | 附件提取 | 提取文章附件下载链接 |
| **数据清洗** | 数据去重 | 根据标题、URL等特征识别并过滤重复文章 |
| | 数据标准化 | 统一时间格式、部门名称等 |
| | 敏感词过滤 | 过滤无效或敏感内容 |
| **数据存储** | 持久化存储 | 将清洗后的数据存入数据库 |
| | 数据版本管理 | 支持数据历史版本追溯 |

## 八、查询统计

| 二级功能目录 | 三级功能目录 | 功能描述 |
|--------------|--------------|----------|
| **数据统计** | 爬取统计 | 按月、季度、年、部门展示爬取总文章数 |
| | 发布统计 | 按月、季度、年、部门、监督维度展示发布文章数 |
| | 匹配项统计 | 展示系统识别出的监督事项文章数量 |
| | 完成率计算 | 按月、季度、年、部门、监督分类计算完成率 |
| | 详情下钻 | 点击统计指标，展示每篇文章的详细列表 |
| **图表分析** | 事项分布图表 | 按时间和部门以饼图展示各监督事项文章分布 |
| | 趋势分析图表 | 以时间、部门维度折线图展示趋势变化 |
| | 柱状图展示 | 按部门或分类展示文章数量对比 |
| | 图表交互 | 点击图表筛选对应文章列表 |

## 开发优先级

| 优先级 | 模块 | 说明 |
|--------|------|------|
| P0 | 数据采集与处理 | 爬虫引擎是基础 |
| P0 | 查询统计 | 数据展示核心功能 |
| P1 | 监督事项管理 | 监督业务基础数据 |
| P1 | 关键词库管理 | 智能分析基础 |
| P1 | 智能分析引擎 | 核心智能功能 |
| P2 | 用户与权限管理 | 系统管理功能 |
| P2 | 数据源管理 | 扩展数据源 |
| P2 | 爬虫调度管理 | 定时任务管理 |
| P3 | 文章管理 | 补充功能 |
| P3 | 文章详情 | 补充功能 |
| P3 | 报告生成 | 扩展功能 |

## 技术选型建议

| 组件 | 推荐技术 |
|------|----------|
| 后端框架 | Python Flask / FastAPI |
| 数据库 | PostgreSQL / MySQL |
| 前端框架 | Vue3 + Element Plus |
| 爬虫框架 | Playwright + BeautifulSoup |
| NLP引擎 | HanLP / Jieba + 规则引擎 |
| 定时任务 | APScheduler |
| 图表库 | ECharts |
| 报告生成 | python-docx |
