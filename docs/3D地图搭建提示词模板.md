## 核心技术说明

### 1. 双层标记系统（解决点击难题）

**问题**：3D 地图上的小标记很难点击

**解决方案**：
```javascript
series: [
    // 第一层：隐形大热区（负责捕捉点击）
    {
        type: 'scatter3D',
        coordinateSystem: 'geo3D',
        symbol: 'circle',
        symbolSize: 200,  // 超大触发区域
        itemStyle: {
            color: '#ffffff',
            opacity: 0.001  // 几乎透明，肉眼看不见
        },
        silent: false,  // 可响应事件
        data: cities.map(city => ({
            name: city.name,
            value: [...city.coord, 3]  // 高度为3，悬浮在地图上方
        }))
    },
    // 第二层：可见标记（负责视觉展示）
    {
        type: 'scatter3D',
        coordinateSystem: 'geo3D',
        symbol: 'pin',
        symbolSize: 30,
        itemStyle: { color: '#ea4335' },
        label: { show: true },
        data: cities.map(city => ({
            name: city.name,
            value: [...city.coord, 15]  // 高度为15，显示在上方
        }))
    }
]
```

### 2. 点击事件处理（区分点击和拖拽）

```javascript
let activeRegion = '';
let mouseDownTime = 0;

// 记录鼠标悬停的城市
chart.on('mousemove', function (params) {
    if (params.seriesType === 'scatter3D' && params.name) {
        activeRegion = params.name;
        document.body.style.cursor = 'pointer';
    }
});

// 记录鼠标按下时间
chart.getZr().on('mousedown', function () {
    mouseDownTime = Date.now();
});

// 判断是点击还是拖拽
chart.getZr().on('mouseup', function () {
    let timeDiff = Date.now() - mouseDownTime;
    
    // 时间差 < 300ms 且鼠标在城市热区内 = 点击
    if (timeDiff < 300 && activeRegion !== '') {
        handleRegionClick(activeRegion);
    }
});
```

### 3. 防弹窗拦截跳转

```javascript
function handleRegionClick(regionName) {
    const targetUrl = cityLinks[regionName];
    
    if (targetUrl) {
        // 创建隐藏链接并模拟点击
        const link = document.createElement('a');
        link.href = targetUrl;
        link.target = '_blank';
        document.body.appendChild(link);
        link.click();
        document.body.removeChild(link);
    }
}
```

### 4. 地图配置要点

```javascript
geo3D: {
    map: 'mapName',
    roam: true,  // 允许拖拽和缩放
    boxHeight: 6,  // 3D 盒子高度
    regionHeight: 2.5,  // 区域高度
    
    // 自动旋转
    viewControl: {
        distance: 90,  // 视角距离
        alpha: 40,  // 上下旋转角度
        beta: 10,  // 左右旋转角度
        autoRotate: true,  // 自动旋转
        autoRotateSpeed: 1.5  // 旋转速度
    },
    
    // 光照效果
    light: {
        main: { intensity: 1.5, shadow: true },
        ambient: { intensity: 0.6 }
    },
    
    // 不同区域不同样式
    regions: geoJson.features.map(feature => ({
        name: feature.properties.name,
        height: calculateHeight(feature),  // 自定义高度
        itemStyle: { color: calculateColor(feature) }  // 自定义颜色
    }))
}
```

## 常见问题解决

### Q1: 标记点击不灵敏？
**A**: 增大 `hotspotSize` 值（默认200，可调整到300-500）

### Q2: 地图加载失败？
**A**: 检查 GeoJSON URL 是否正确，确保行政区划代码正确

### Q3: 如何获取城市坐标？
**A**: 使用百度地图拾取坐标工具：https://api.map.baidu.com/lbsapi/getpoint/

### Q4: 如何禁用自动旋转？
**A**: 设置 `viewControl.autoRotate: false`

### Q5: 如何调整视角？
**A**: 修改 `viewControl` 中的 `distance`（距离）、`alpha`（俯仰角）、`beta`（方位角）

## 性能优化建议

1. **减少标记数量**：超过50个标记时考虑聚合
2. **关闭阴影**：`light.main.shadow: false`
3. **降低分辨率**：`postEffect.enable: false`
4. **按需加载**：使用懒加载技术
