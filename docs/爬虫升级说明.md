# 清风网爬虫服务升级说明

> **升级版本**：v1.0 → v2.0  
> **升级时间**：2025-12-17  
> **升级类型**：功能增强

---

## 📋 升级概述

### 升级前（v1.0）

- ❌ 只能爬取首页（index.htm）的部分内容
- ❌ 无法区分不同分类的新闻
- ❌ 数据结构简单，缺少分类信息
- ❌ 无法按需获取特定分类的新闻

### 升级后（v2.0）

- ✅ 爬取审查调查页面（scdc.htm）的所有侧边栏菜单
- ✅ 支持4个子分类的独立爬取
- ✅ 数据结构完整，包含分类、子分类、类型标识
- ✅ 支持按分类和子分类过滤
- ✅ 新增分类列表API
- ✅ 完整的测试套件

## 🎯 新增功能

### 1. 多分类爬取

**支持的分类**：

| 主分类 | 子分类 | 类型标识 |
|--------|--------|---------|
| 省管干部 | 执纪审查 | `provincial_discipline` |
| 省管干部 | 党纪政务处分 | `provincial_punishment` |
| 其他干部 | 执纪审查 | `other_discipline` |
| 其他干部 | 党纪政务处分 | `other_punishment` |

### 2. 数据字段增强

**v1.0 数据结构**：
```json
{
  "title": "新闻标题",
  "date": "2025-12-17",
  "source": "清风网",
  "url": "https://..."
}
```

**v2.0 数据结构**：
```json
{
  "title": "新闻标题",
  "summary": "新闻摘要",
  "date": "2025-12-17",
  "url": "https://...",
  "source": "清风网",
  "category": "省管干部",
  "subcategory": "执纪审查",
  "type": "provincial_discipline"
}
```

### 3. 新增API接口

| 接口 | 功能 | 示例 |
|------|------|------|
| `/api/news` | 获取所有新闻（支持过滤） | `?category=省管干部` |
| `/api/categories` | 获取分类列表 | - |
| `/health` | 健康检查（增强） | - |

### 4. 查询参数支持

```bash
# 按主分类过滤
/api/news?category=省管干部

# 按子分类过滤
/api/news?category=省管干部&subcategory=执纪审查

# 限制返回数量
/api/news?limit=10

# 组合使用
/api/news?category=其他干部&subcategory=党纪政务处分&limit=5
```

## 📝 使用变更

### API调用变更

**v1.0**：
```javascript
// 只能获取所有新闻
fetch('http://localhost:5000/api/news')
```

**v2.0**：
```javascript
// 获取所有新闻
fetch('http://localhost:5000/api/news')

// 获取省管干部新闻
fetch('http://localhost:5000/api/news?category=省管干部')

// 获取省管干部的执纪审查新闻
fetch('http://localhost:5000/api/news?category=省管干部&subcategory=执纪审查')

// 获取分类列表
fetch('http://localhost:5000/api/categories')
```

### 数据处理变更

**v1.0**：
```javascript
// 简单显示
news.forEach(item => {
    console.log(item.title, item.date);
});
```

**v2.0**：
```javascript
// 可以按分类分组
const grouped = {};
news.forEach(item => {
    const key = `${item.category}-${item.subcategory}`;
    if (!grouped[key]) grouped[key] = [];
    grouped[key].push(item);
});

// 可以按类型过滤
const provincialDiscipline = news.filter(
    item => item.type === 'provincial_discipline'
);
```

## 🚀 迁移指南

### 步骤1：更新代码

如果您已经在使用v1.0，请按以下步骤升级：

1. **备份当前文件**：
   ```bash
   copy crawler_server.py crawler_server_v1.py.bak
   ```

2. **替换为新版本**：
   - 使用新的 `crawler_server.py`

3. **重启服务**：
   ```bash
   # 停止旧服务（Ctrl+C）
   # 启动新服务
   python crawler_server.py
   ```

### 步骤2：更新前端代码

如果您的前端代码依赖旧的数据结构，需要进行以下调整：

**旧代码**：
```javascript
fetch('http://localhost:5000/api/news')
    .then(res => res.json())
    .then(data => {
        data.forEach(news => {
            console.log(news.title);
        });
    });
```

**新代码**：
```javascript
fetch('http://localhost:5000/api/news')
    .then(res => res.json())
    .then(result => {
        result.data.forEach(news => {
            console.log(news.title, news.category, news.subcategory);
        });
    });
```

**注意**：响应结构从直接返回数组变为包含 `code`、`message`、`data` 的对象。
