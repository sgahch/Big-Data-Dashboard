## 使用说明

### 访问页面
```
http://localhost:8000/
```

### 页面切换
点击顶部导航栏的4个标签即可切换页面

### 视频配置
如需更换视频，请将视频文件放到项目根目录的 `static` 文件夹，并命名为 `demo.mp4`

或者修改 index.html 中的视频路径：
```html
<source src="/你的视频路径.mp4" type="video/mp4">
```

### 统计数据
当前使用的是假数据，如需显示真实数据，可以：
1. 通过API获取数据
2. 修改 index.html 中的统计数值
