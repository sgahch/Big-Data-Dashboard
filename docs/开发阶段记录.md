## 第四阶段：AI智能客服开发 ✅
**完成时间**: 2026-01-31

### 4.1 功能概述
基于 Coze AI 平台的智能客服，为纪检监察系统提供 AI 对话服务。

### 4.2 配置说明

#### Coze 平台配置
1. 访问 [Coze 官网](https://www.coze.cn/)
2. 登录后创建或选择已有的 Bot（机器人）
3. 获取 Bot ID
4. 在 API 令牌管理中创建新的 API Token

#### 环境变量配置
```bash
# .env 文件
COZE_API_TOKEN=your_api_token_here
COZE_BOT_ID=your_bot_id_here
```

#### 依赖安装
```bash
pip install cozepy
```

### 4.4 关键代码 (server.py)

#### 客户端初始化
```python
# 使用官方 SDK cozepy
try:
    from cozepy import Coze, TokenAuth, COZE_CN_BASE_URL, Message, ChatEventType
    COZE_SDK_AVAILABLE = True
except ImportError:
    COZE_SDK_AVAILABLE = False
    print("⚠️ cozepy SDK 未安装，AI客服功能不可用")

_coze_client = None
def get_coze_client():
    """获取 Coze 客户端单例"""
    global _coze_client
    if _coze_client is None and COZE_SDK_AVAILABLE:
        _coze_client = Coze(
            auth=TokenAuth(token=COZE_API_TOKEN),
            base_url=COZE_CN_BASE_URL
        )
    return _coze_client
```

#### 对话接口实现
```python
@app.route('/api/ai/chat/', methods=['POST', 'OPTIONS'])
@app.route('/api/ai/chat', methods=['POST', 'OPTIONS'])
def coze_chat():
    """Coze AI客服代理API - 使用官方SDK流式响应"""
    try:
        data = request.get_json(force=True, silent=True)
        user_message = data.get('message', '')
        user_id = data.get('user_id', f'user_{int(time.time())}')

        if not user_message:
            return jsonify({'code': -1, 'message': '消息内容不能为空'}), 400

        # 使用官方 SDK
        coze = get_coze_client()
        ai_reply = ''

        for event in coze.chat.stream(
            bot_id=COZE_BOT_ID,
            user_id=str(user_id),
            additional_messages=[
                Message.build_user_question_text(user_message),
            ],
        ):
            if event.event == ChatEventType.CONVERSATION_MESSAGE_DELTA:
                content = event.message.content
                if content:
                    ai_reply += content

        return jsonify({
            'code': 0,
            'message': 'success',
            'data': {'reply': ai_reply},
            'timestamp': datetime.now().isoformat()
        })

    except Exception as e:
        return jsonify({
            'code': -1,
            'message': f'AI客服调用失败: {str(e)}',
            'data': None
        }), 500
```

### 4.5 常见问题

#### Token 无效 (code 4101)
**错误**: `The token you entered is incorrect`
**解决**:
1. 登录 Coze 官网检查 Token 是否有效
2. 重新创建 API Token
3. 确保 `.env` 文件中的 Token 与使用的 Token 一致

#### SDK 导入失败
**错误**: `ModuleNotFoundError: No module named 'cozepy'`
**解决**:
```bash
pip install cozepy
```
