## 📋 常见任务快速索引

### 任务1：首次启动项目

**步骤**：
1. 阅读 [README.md](./README.md) 的"快速启动"部分
2. 双击打开 `index.html`

- [README.md](./README.md) - 第19-45行

---

### 任务2：切换到其他智能体

**步骤**：
1. 阅读 [智能体切换快速参考.md](./智能体切换快速参考.md)
2. 获取新智能体的Bot ID和API Key
3. 修改 `index.html` 第404-405行
4. 刷新浏览器测试

**相关文档**：
- [智能体切换快速参考.md](./智能体切换快速参考.md) - 完整流程
- [Coze智能体接入指南.md](./Coze智能体接入指南.md) - 第2章"获取智能体信息"

---

### 任务3：测试Coze API连接

**步骤**：
1. 打开终端/命令行
2. 运行 `python test_coze_api.py`
3. 查看测试结果

**相关文档**：
- [Coze智能体接入指南.md](./Coze智能体接入指南.md) - 第7章"API测试工具"

---

### 任务4：排查AI无法回复的问题

**步骤**：
1. 按F12打开浏览器开发者工具
2. 查看Console中的错误信息
3. 参考故障排查文档

**相关文档**：
- [智能体切换快速参考.md](./智能体切换快速参考.md) - "常见错误速查"表格
- [Coze智能体接入指南.md](./Coze智能体接入指南.md) - 第6章"常见问题排查"
- [Coze智能体技术实现文档.md](./Coze智能体技术实现文档.md) - 第4章"错误处理机制"

---

### 任务5：配置多个智能体并快速切换

**步骤**：
1. 打开 [bot_config_template.js](./bot_config_template.js)
2. 复制内容到 `index.html` 的配置区域
3. 填写多个智能体的配置信息
4. 修改 `CURRENT_BOT` 变量即可切换

**相关文档**：
- [bot_config_template.js](./bot_config_template.js) - 完整代码模板
- [Coze智能体技术实现文档.md](./Coze智能体技术实现文档.md) - 第9.3节"多智能体配置管理"

---

### 任务6：自定义AI欢迎语

**步骤**：
1. 打开 `index.html`
2. 找到 `initAIChat()` 函数（约第697行）
3. 修改欢迎语内容
4. 保存并刷新浏览器

**相关文档**：
- [Coze智能体技术实现文档.md](./Coze智能体技术实现文档.md) - 第2.2节"UI初始化"
