# 报告导出功能说明

## 功能概述

系统支持将纪检监察数据分析报告导出为三种格式：
- **PDF** - 便于阅读和打印的便携式文档
- **Word (DOCX)** - 可编辑的文档格式
- **Excel (XLSX)** - 数据分析表格格式

## 使用方法

### 前端使用

1. 进入"数据处理"页面
2. 点击右下角的"导出报告"按钮
3. 在弹出的格式选择窗口中选择需要的格式（PDF/Word/Excel）
4. 点击"确认导出"按钮
5. 浏览器会自动下载生成的报告文件

### API调用

#### 预览报告数据
```bash
GET /api/stats/report?type=word
```

#### 生成并下载报告
```bash
POST /api/stats/report
Content-Type: application/json

{
  "type": "word"  // 可选值: "word", "excel", "pdf"
}
```

## 报告内容

所有格式的报告都包含以下内容：

### 一、数据概览
- 总新闻数
- 今日新增
- 昨日新增
- 活跃地区
- 今日爬取
- 今日新增

### 二、违规事项分布
- 按违规类型统计
- Top 15 违规类型排行

### 三、案件查处趋势
- 按月统计案件数量
- 环比变化分析

### 四、地区分布统计
- 各地区新闻数量
- 占比分析

### 五、最新通报案例
- 最新20条新闻列表
- 包含标题、来源、日期等信息

## 格式特点

### PDF格式
- ✅ 适合打印和分享
- ✅ 格式固定，不可编辑
- ✅ 支持中文字体
- ⚠️ 需要安装 weasyprint 或 xhtml2pdf

### Word格式
- ✅ 可编辑修改
- ✅ 支持表格和样式
- ✅ 兼容性好
- ✅ 无需额外依赖

### Excel格式
- ✅ 多工作表分类
- ✅ 便于数据分析
- ✅ 支持公式和图表
- ✅ 包含详细统计

## 技术实现

### 后端实现
- **位置**: `apps/stats/report.py`
- **视图**: `apps/stats/views.py` - `ReportGenerateView`
- **路由**: `/api/stats/report`

### 前端实现
- **位置**: `index.html`
- **函数**: 
  - `exportReport()` - 打开格式选择弹窗
  - `selectExportFormat(format)` - 选择导出格式
  - `confirmExport()` - 确认并执行导出

### 依赖库

#### Word导出


#### Excel导出

## 故障排除

### PDF生成失败
**问题**: PDF生成时报错
**解决方案**:
1. 安装PDF生成库：`pip install weasyprint xhtml2pdf reportlab`
2. Windows系统需要安装GTK+运行时（weasyprint依赖）
3. 如果weasyprint安装失败，系统会自动使用xhtml2pdf作为备选

### 中文显示问题
**问题**: PDF中中文显示为方框
**解决方案**:
- 系统会自动查找系统中的中文字体
- Windows: 微软雅黑、黑体、宋体
- macOS: PingFang、STHeiti
- Linux: Noto Sans CJK、WenQuanYi

### 文件下载失败
**问题**: 点击导出后没有下载
**解决方案**:
1. 检查浏览器控制台是否有错误
2. 检查后端服务是否正常运行
3. 检查网络连接
4. 尝试更换浏览器

## 数据来源问题修复

### 问题描述
排行榜只显示20条数据，但数据库有100多条。

### 原因分析
Django REST Framework的分页设置限制了每页返回的数据量。

### 解决方案
1. **后端修改** - 增加默认分页大小
   - 文件: `supervision/settings.py`
   - 修改: `PAGE_SIZE: 20` → `PAGE_SIZE: 500`

2. **前端修改** - 添加page_size参数
   - 文件: `index.html`
   - 修改: `/api/news/` → `/api/news/?page_size=1000`

### 验证
1. 重启Django服务
2. 刷新页面
3. 检查浏览器控制台，应该看到：`✅ 成功加载真实数据: XXX 条`
