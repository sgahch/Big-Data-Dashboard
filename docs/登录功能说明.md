# 登录功能说明

## 功能概述

系统已添加完整的登录/登出功能，确保只有登录用户才能访问主界面。

## 功能特性

### 1. 登录页面 (`login.html`)
- 用户名和密码输入
- 记住我功能（保存用户名）
- 自动检测登录状态（已登录自动跳转）
- 登录成功后保存状态到 localStorage

### 2. 主界面 (`index.html`)
- 页面加载时自动检查登录状态
- 未登录自动跳转到登录页面
- 显示当前登录用户名
- 右上角登出按钮

### 3. 登出功能
- 点击登出按钮弹出确认对话框
- 清除登录状态
- 自动跳转回登录页面

## 使用流程

### 首次访问
1. 访问 `http://localhost:8000/` 或 `http://localhost:8000/index.html`
2. 系统检测到未登录，自动跳转到 `/login.html`
3. 输入用户名和密码登录
4. 登录成功后跳转到主界面

### 已登录用户
1. 直接访问主界面，无需重复登录
2. 右上角显示用户名和登出按钮
3. 点击登出按钮可退出登录

### 登出后
1. 清除所有登录状态
2. 自动跳转到登录页面
3. 需要重新登录才能访问主界面

## 技术实现

### 登录状态存储
使用 `localStorage` 存储登录状态：
- `isLoggedIn`: 'true' 表示已登录
- `username`: 当前登录的用户名
- `remembered_username`: 记住的用户名（勾选"记住我"时）

### 登录检查逻辑
```javascript
function checkLogin() {
    const username = localStorage.getItem('username');
    const isLoggedIn = localStorage.getItem('isLoggedIn');
    
    if (!isLoggedIn || isLoggedIn !== 'true') {
        window.location.href = '/login.html';
        return false;
    }
    
    if (username) {
        document.getElementById('current-username').textContent = username;
    }
    
    return true;
}
```

### 登出逻辑
```javascript
function logout() {
    if (confirm('确定要退出登录吗？')) {
        localStorage.removeItem('username');
        localStorage.removeItem('isLoggedIn');
        window.location.href = '/login.html';
    }
}
```

## 注意事项

1. **首次使用**：需要先在后台创建用户账号
2. **安全性**：当前使用 localStorage 存储，生产环境建议使用 JWT Token
3. **会话保持**：关闭浏览器后登录状态会保留（除非清除浏览器数据）
4. **多标签页**：在一个标签页登出会影响所有标签页
