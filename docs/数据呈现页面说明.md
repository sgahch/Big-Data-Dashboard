# 数据呈现页面更新说明

## 更新内容

已完成第三个页面（数据呈现页面）的开发，添加了两个核心统计图表。

## 页面布局

### 左侧：案件查处呈现统计
- **图表类型**：柱状图 + 折线图组合
- **展示内容**：
  - 柱状图：各类违规案件数量
  - 折线图1：各类案件占比（%）
  - 折线图2：累积趋势
- **数据来源**：`/api/stats/cases/?months=12`
- **备用数据**：Mock数据（8种违规类型）

### 右侧：违规事项分布呈现
- **图表类型**：玫瑰图（Rose Chart）
- **展示内容**：各类违规事项的分布情况
- **数据来源**：`/api/stats/violations/`
- **备用数据**：Mock数据（6种违规事项）

## 功能特性

### 1. 自动数据加载
- 切换到数据呈现页面时自动加载图表
- 优先从API获取真实数据
- API失败时自动降级使用Mock数据

### 2. 响应式设计
- 图表自动适应窗口大小
- 左右两栏等宽布局
- 支持窗口缩放自动调整

### 3. 交互效果
- 鼠标悬停显示详细数据
- 图例点击切换显示/隐藏
- 图表元素高亮效果

### API接口

#### 1. 违规事项分布
- **URL**: `/api/stats/violations/`
- **方法**: GET
- **返回格式**:
```json
{
    "code": 0,
    "data": [
        {"name": "违规类型", "value": 数量}
    ]
}
```

#### 2. 案件查处统计
- **URL**: `/api/stats/cases/?months=12`
- **方法**: GET
- **返回格式**:
```json
{
    "code": 0,
    "data": {
        "tag_stats": [
            {"name": "标签名称", "value": 数量}
        ]
    }
}
```

## 图表配置

### 违规事项分布（玫瑰图）
- **配色方案**：8色渐变（粉红、橙色、黄色、青色、紫色、绿色等）
- **半径**：内圈30%，外圈70%
- **标签**：显示名称和数量
- **动画**：悬停放大效果

### 案件查处统计（组合图）
- **柱状图**：渐变色（青色到紫色）
- **折线图1**：粉红色，显示占比
- **折线图2**：绿色虚线，显示累积趋势
- **双Y轴**：左侧案件数，右侧占比
- **X轴标签**：旋转30度避免重叠

## 样式设计

### 面板样式
- 背景：半透明深蓝色 `rgba(11, 15, 42, 0.8)`
- 边框：青色发光边框 `rgba(0, 210, 255, 0.3)`
- 阴影：青色光晕效果
- 毛玻璃效果：`backdrop-filter: blur(10px)`

### 标题样式
- 颜色：青色 `#00D2FF`
- 字体大小：18px
- 图标：FontAwesome图标
- 底部边框：青色分隔线

## 使用方法

1. 点击顶部导航栏的"数据呈现"按钮
2. 系统自动加载两个图表
3. 等待数据加载完成（约1-2秒）
4. 可以与图表进行交互（悬停、点击图例等）

## 注意事项

1. **首次加载**：如果API未配置，会自动使用Mock数据
2. **性能优化**：切换页面时才初始化图表，避免资源浪费
3. **响应式**：窗口大小改变时图表自动调整
4. **错误处理**：API失败时自动降级到Mock数据，不影响用户体验
