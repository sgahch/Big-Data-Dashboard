# 3D地图技术实现（精简版）

## 一、给 AI 的提示词

```
使用 ECharts GL 创建 3D 地图，要求：
1. 地图数据：阿里云 DataV GeoJSON API
2. 自动旋转 + 鼠标交互（拖拽、缩放）
3. 双层标记系统：透明大热区（symbolSize: 200, opacity: 0.001）+ 可见 pin 标记（symbolSize: 30）
4. 点击判断：ZRender mousedown/mouseup，时间差 < 300ms = 点击
5. 防弹窗拦截：创建隐藏 <a> 标签并模拟点击
6. 地图区域：[省份名称]，行政区划代码：[代码]
7. 城市列表：[城市1, 城市2, ...]，每个城市包含坐标和跳转链接
```

### 2. 配置区域
```javascript
// 地图配置
const MAP_CONFIG = {
    geoJsonUrl: 'https://geo.datav.aliyun.com/areas_v3/bound/610000_full.json'  // 610000=陕西
};

// 城市配置
const CITIES = {
    '西安': { coord: [108.9398, 34.3416], url: 'https://example.com/xian' },
    '宝鸡': { coord: [107.2371, 34.3619], url: 'https://example.com/baoji' }
};

// 样式配置
const STYLE = {
    markerHeight: 15,      // 标记高度
    hotspotSize: 200,      // 热区大小
    markerSize: 30,        // 标记大小
    markerColor: '#ea4335',
    rotateSpeed: 1.5
};
```

### 3. 双层标记系统
```javascript
series: [
    // 第一层：隐形大热区（捕捉点击）
    {
        type: 'scatter3D',
        coordinateSystem: 'geo3D',
        symbol: 'circle',
        symbolSize: STYLE.hotspotSize,
        itemStyle: { color: '#fff', opacity: 0.001 },
        silent: false,
        data: Object.entries(CITIES).map(([name, info]) => ({
            name: name,
            value: [...info.coord, 3]
        }))
    },
    // 第二层：可见标记（视觉展示）
    {
        type: 'scatter3D',
        coordinateSystem: 'geo3D',
        symbol: 'pin',
        symbolSize: STYLE.markerSize,
        itemStyle: { color: STYLE.markerColor },
        label: {
            show: true,
            position: 'top',
            formatter: '{b}',
            textStyle: {
                color: '#333',
                fontSize: 12,
                backgroundColor: '#fff',
                padding: [3, 6],
                borderRadius: 8
            }
        },
        data: Object.entries(CITIES).map(([name, info]) => ({
            name: name,
            value: [...info.coord, STYLE.markerHeight]
        }))
    }
]
```

### 4. 点击事件处理
```javascript
let activeRegion = '';
let mouseDownTime = 0;

// 记录悬停城市
chart.on('mousemove', params => {
    if (params.seriesType === 'scatter3D' && params.name) {
        activeRegion = params.name;
        document.body.style.cursor = 'pointer';
    }
});

chart.on('mouseout', () => {
    activeRegion = '';
    document.body.style.cursor = 'default';
});

// 记录按下时间
chart.getZr().on('mousedown', () => {
    mouseDownTime = Date.now();
});

// 判断点击/拖拽
chart.getZr().on('mouseup', () => {
    const timeDiff = Date.now() - mouseDownTime;
    if (timeDiff < 300 && activeRegion) {
        handleClick(activeRegion);
    }
});
```

### 5. 防弹窗拦截跳转
```javascript
function handleClick(cityName) {
    const cityInfo = CITIES[cityName];
    if (!cityInfo || !cityInfo.url) return;
    
    const link = document.createElement('a');
    link.href = cityInfo.url;
    link.target = '_blank';
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
}
```

### 6. 地图配置
```javascript
geo3D: {
    map: 'mapName',
    roam: true,
    boxHeight: 6,
    regionHeight: 2.5,
    viewControl: {
        distance: 90,
        alpha: 40,
        beta: 10,
        autoRotate: true,
        autoRotateSpeed: STYLE.rotateSpeed
    },
    light: {
        main: { intensity: 1.5, shadow: true },
        ambient: { intensity: 0.6 }
    },
    itemStyle: {
        color: '#ffffff',
        borderWidth: 1.5,
        borderColor: '#81c784'
    },
    emphasis: {
        itemStyle: { color: '#4285F4' },
        label: { show: true }
    }
}
```

### 7. 完整初始化代码
```javascript
const chart = echarts.init(document.getElementById('map'));

async function init() {
    const res = await fetch(MAP_CONFIG.geoJsonUrl);
    const geoJson = await res.json();
    echarts.registerMap('mapName', geoJson);
    
    chart.setOption({
        backgroundColor: 'transparent',
        geo3D: { /* 见上面配置 */ },
        series: [ /* 见双层标记系统 */ ]
    });
    
    // 绑定事件（见点击事件处理）
    window.addEventListener('resize', () => chart.resize());
}

init();
```

## 三、快速配置

### 行政区划代码
```
100000 = 全国
110000 = 北京
310000 = 上海
440000 = 广东
610000 = 陕西
```

### 获取坐标
百度地图拾取：https://api.map.baidu.com/lbsapi/getpoint/

### 自定义区域高度
```javascript
regions: geoJson.features.map(feature => {
    const name = feature.properties.name;
    let height = 1.0;
    if (name === '重点区域') height = 4.0;
    return { name, height, itemStyle: { color: '#fff' } };
})
```
