## 🎯 功能概览

### 爬取范围

本爬虫服务能够自动爬取清风网（https://www.qinfeng.gov.cn/scdc.htm）的以下所有分类：

```
清风网 - 审查调查页面
│
├── 省管干部
│   ├── 执纪审查
│   └── 党纪政务处分
│
└── 其他干部
    ├── 执纪审查
    └── 党纪政务处分
```

### 数据结构

每条新闻包含以下完整信息：

```json
{
  "title": "陕西中医药大学副校长缪峰接受纪律审查和监察调查",
```

## 🔧 前端集成示例

### JavaScript代码

```javascript
// 获取所有新闻并按分类分组
async function fetchAndGroupNews() {
    const response = await fetch('http://localhost:5000/api/news');
    const result = await response.json();
    
    if (result.code === 0) {
        const grouped = {};
        
        result.data.forEach(news => {
            const key = `${news.category}-${news.subcategory}`;
            if (!grouped[key]) {
                grouped[key] = [];
            }
            grouped[key].push(news);
        });
        
        console.log('按分类分组的新闻:', grouped);
        return grouped;
    }
}

// 获取省管干部的执纪审查新闻
async function fetchProvincialDiscipline() {
    const response = await fetch(
        'http://localhost:5000/api/news?category=省管干部&subcategory=执纪审查'
    );
    const result = await response.json();
    
    if (result.code === 0) {
        console.log('省管干部执纪审查:', result.data);
        return result.data;
    }
}

// 更新滚动列表
async function updateScrollingList() {
    const response = await fetch('http://localhost:5000/api/news?limit=20');
    const result = await response.json();
    
    if (result.code === 0) {
        const listHTML = result.data.map((news, index) => `
            <tr onclick="window.open('${news.url}', '_blank')">
                <td>${index + 1}</td>
                <td class="news-title">${news.title}</td>
                <td>${news.date}</td>
                <td>${news.category} > ${news.subcategory}</td>
            </tr>
        `).join('');
        
        document.querySelector('#news-table tbody').innerHTML = listHTML;
    }
}
```

## 📈 数据统计示例

### 按分类统计案件数量

```javascript
async function getStatsByCategory() {
    const response = await fetch('http://localhost:5000/api/news');
    const result = await response.json();
    
    if (result.code === 0) {
        const stats = {
            '省管干部-执纪审查': 0,
            '省管干部-党纪政务处分': 0,
            '其他干部-执纪审查': 0,
            '其他干部-党纪政务处分': 0
        };
        
        result.data.forEach(news => {
            const key = `${news.category}-${news.subcategory}`;
            stats[key]++;
        });
        
        console.log('分类统计:', stats);
        
        // 可用于ECharts图表
        return {
            categories: Object.keys(stats),
            values: Object.values(stats)
        };
    }
}
```

```javascript
async function updateViolationChart() {
    const stats = await getStatsByCategory();
    
    const chartData = stats.categories.map((cat, index) => ({
        name: cat,
        value: stats.values[index]
    }));
    
    // 更新ECharts图表
    violationChart.setOption({
        series: [{
            data: chartData
        }]
    });
}
```

### 场景3：案件查处统计

按月份统计案件数量：

```javascript
async function getMonthlyStats() {
    const response = await fetch('http://localhost:5000/api/news');
    const result = await response.json();
    
    if (result.code === 0) {
        const monthlyStats = {};
        
        result.data.forEach(news => {
            const month = news.date.substring(0, 7);  // YYYY-MM
            monthlyStats[month] = (monthlyStats[month] || 0) + 1;
        });
        
        return monthlyStats;
    }
}
```

## 📝 注意事项

1. **数据更新频率**：建议每5-10分钟调用一次API
2. **请求限制**：爬虫内置0.5秒延迟，避免请求过快
3. **错误处理**：如果爬虫失败，API会自动返回Mock数据
4. **CORS支持**：已配置跨域支持，可直接从前端调用
