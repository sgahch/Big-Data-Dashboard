## 🚀 快速开始

### 方式一：使用模板（推荐）

1. 打开 `3d_map_template.html`
2. 修改配置区域：
   ```javascript
   // 1. 修改地图区域
   const MAP_CONFIG = {
       geoJsonUrl: 'https://geo.datav.aliyun.com/areas_v3/bound/你的行政区划代码_full.json'
   };
   
   // 2. 修改城市列表
   const CITIES = {
       '城市名': { coord: [经度, 纬度], url: '链接' }
   };
   
   // 3. 修改样式（可选）
   const STYLE_CONFIG = { ... };
   ```
3. 保存并在浏览器中打开

### 方式二：让 AI 生成

1. 复制 `AI提示词-3D地图搭建.md` 中的提示词
2. 粘贴给 AI（ChatGPT、Claude、Kimi 等）
3. 根据需求修改提示词中的地图区域和城市列表
4. AI 会生成完整的 HTML 代码

## 🎯 核心技术

### 1. 双层标记系统
解决 3D 地图标记难以点击的问题：
- **第一层**：透明大圆（symbolSize: 200），负责捕捉点击
- **第二层**：可见标记（symbolSize: 30），负责视觉展示

### 2. 智能点击判断
区分点击和拖拽操作：
- 记录 mousedown 时间
- mouseup 时计算时间差
- 时间差 < 300ms = 点击，否则 = 拖拽

### 3. 防弹窗拦截
确保链接能正常打开：
```javascript
const link = document.createElement('a');
link.href = url;
link.target = '_blank';
document.body.appendChild(link);
link.click();
document.body.removeChild(link);
```

    const name = feature.properties.name;
    let height = 1.0;  // 默认高度

    return { name, height, itemStyle: { color: '#fff' } };

## 🔧 常见问题

### Q: 标记点击不灵敏？
**A**: 增大 `hotspotSize` 值（默认 200，可调到 300-500）

### Q: 地图加载失败？
**A**: 检查 GeoJSON URL 中的行政区划代码是否正确

### Q: 如何禁用自动旋转？
**A**: 设置 `viewControl.autoRotate: false`

### Q: 如何调整视角？
**A**: 修改 `viewControl` 中的参数：
- `distance`: 视角距离（默认 90）
- `alpha`: 俯仰角（默认 40）
- `beta`: 方位角（默认 10）

### Q: 如何嵌入到其他页面？
**A**: 使用 iframe：
```html
<iframe src="3d_map.html" width="100%" height="600px"></iframe>
```
