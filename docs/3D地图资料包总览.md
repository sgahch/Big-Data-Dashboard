## 🚀 5 分钟快速开始

### 步骤 1：选择地图区域

访问：https://datav.aliyun.com/portal/school/atlas/area_selector

找到你需要的地图区域代码，例如：
- 陕西省：610000
- 广东省：440000
- 北京市：110000

### 步骤 2：获取城市坐标

访问：https://api.map.baidu.com/lbsapi/getpoint/

搜索城市，点击地图获取坐标。

### 步骤 3：修改模板

打开 `3d_map_template.html`，修改配置：

```javascript
// 修改地图区域
const MAP_CONFIG = {
    geoJsonUrl: 'https://geo.datav.aliyun.com/areas_v3/bound/610000_full.json'
};

// 修改城市列表
const CITIES = {
    '西安': { coord: [108.9398, 34.3416], url: 'https://example.com' },
    // 添加更多城市...
};
```

### 步骤 4：测试

在浏览器中打开 HTML 文件，测试效果。

## 💡 核心技术亮点

### 1. 双层标记系统 ⭐⭐⭐⭐⭐

**问题**：3D 地图上的小标记很难点击

**解决方案**：
- 第一层：透明大圆（symbolSize: 200），负责捕捉点击
- 第二层：可见标记（symbolSize: 30），负责视觉展示

**效果**：点击体验提升 10 倍！

### 2. 智能点击判断 ⭐⭐⭐⭐

**问题**：拖拽地图时误触发点击事件

**解决方案**：
- 记录鼠标按下时间
- 计算时间差
- 时间差 < 300ms = 点击，否则 = 拖拽

**效果**：完美区分点击和拖拽！

### 3. 防弹窗拦截 ⭐⭐⭐

**问题**：`window.open()` 被浏览器拦截

**解决方案**：
- 创建隐藏 `<a>` 标签
- 模拟点击事件

**效果**：100% 打开链接！
