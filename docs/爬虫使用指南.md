# 清风网爬虫服务 v3.0 使用指南

## 🚀 快速开始

### 1. 启动服务

```bash
cd 大数据看板
python start_crawler.py
```

或者：

```bash
python crawler_server.py
```

### 2. 验证服务

打开浏览器访问：
```
http://localhost:5000/health
```

应该看到：
```json
{
  "status": "ok",
  "service": "qinfeng-crawler-v3",
  "version": "3.0",
  "description": "自动爬取所有侧边栏菜单"
}
```

## 🔌 在前端中使用

### JavaScript示例

```javascript
// 获取最新新闻
async function getLatestNews() {
    const response = await fetch('http://localhost:5000/api/news?limit=10');
    const result = await response.json();
    
    if (result.code === 0) {
        console.log(`获取到 ${result.data.length} 条新闻`);
        result.data.forEach(news => {
            console.log(`${news.date} - ${news.title}`);
        });
    }
}

// 按菜单过滤
async function getNewsByMenu(menuName) {
    const response = await fetch(`http://localhost:5000/api/news?menu=${encodeURIComponent(menuName)}`);
    const result = await response.json();
    return result.data;
}

// 使用示例
getLatestNews();
getNewsByMenu('省管干部').then(news => {
    console.log('省管干部新闻:', news);
});
```

## 📊 数据结构

### 新闻对象

```typescript
interface News {
    title: string;        // 新闻标题
    summary: string;      // 摘要（可能为空）
    date: string;         // 发布日期 (YYYY-MM-DD)
    url: string;          // 新闻详情URL
    source: string;       // 来源（固定为"清风网"）
    menu: string;         // 所属菜单
    submenu: string;      // 子菜单（可能为空）
    section: string;      // 板块（如"执纪审查"）
    crawl_time: string;   // 爬取时间
}
```

### API响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": [...],
  "total": 137
}
```

### 场景2: 按分类展示

```javascript
async function loadNewsByCategory() {
    const categories = ['省管干部', '其他干部', '巡视巡察'];
    
    for (const category of categories) {
        const response = await fetch(`http://localhost:5000/api/news?menu=${category}&limit=5`);
        const result = await response.json();
        
        // 渲染到对应的分类区域
        renderCategoryNews(category, result.data);
    }
}
```

### 场景3: 搜索功能

```javascript
async function searchNews(keyword) {
    const response = await fetch('http://localhost:5000/api/news');
    const result = await response.json();
    
    // 客户端过滤
    const filtered = result.data.filter(news => 
        news.title.includes(keyword) || 
        news.summary.includes(keyword)
    );
    
    return filtered;
}
```

## 🐛 故障排查

### 问题1: 服务无法启动

**解决方案**：
```bash
# 检查端口是否被占用
netstat -ano | findstr :5000

# 杀死占用端口的进程
taskkill /PID <进程ID> /F
```

### 问题2: 爬取失败

**解决方案**：
- 检查网络连接
- 查看服务器日志
- 确认清风网是否可访问

### 问题3: 数据为空

**解决方案**：
- 检查API响应中的 `total` 字段
- 如果为0，可能是爬虫首次运行，等待爬取完成
- 查看服务器日志中的爬取进度

---

## 📝 注意事项

1. **请求频率**：爬虫内置0.5秒延迟，避免请求过快
2. **数据更新**：建议每5-10分钟调用一次API
3. **CORS支持**：已配置跨域支持，可直接从前端调用
4. **错误处理**：爬取失败时会返回Mock数据
