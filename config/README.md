# 配置文件说明

## 目录结构
```
config/
├── .env                 # 主环境配置文件（包含敏感信息）
├── .env.example         # 环境配置示例文件
└── README.md           # 本说明文件
```

## 配置说明

### 1. 环境变量文件

- `.env` - 包含实际的环境变量配置，包含敏感信息如数据库密码、API密钥等
- `.env.example` - 配置示例文件，不包含敏感信息，仅作参考

### 2. 配置文件用途

本项目支持从以下位置加载环境变量（按优先级顺序）：
1. `config/.env` - 推荐位置，敏感配置文件
2. 项目根目录的 `.env` - 兼容旧版本（不推荐使用）

### 3. 安全注意事项

- **绝对不要**将包含敏感信息的 `.env` 文件提交到 Git 仓库
- 本目录已添加到 `.gitignore`，确保配置文件不会被意外提交
- 定期更新敏感信息，如数据库密码、API密钥等

### 4. 创建配置文件

如果 `config/.env` 不存在，可按以下步骤创建：

1. 确保已创建 config 目录：
   ```bash
   mkdir config
   ```

2. 从示例文件创建配置：
   ```bash
   cp .env.example config/.env
   ```

3. 编辑 `config/.env` 文件，填入实际的配置信息

### 5. 支持的配置项

请参考 `.env.example` 文件了解所有支持的配置项及其说明。
