## 二、清洗操作步骤

1. 先试运行，核对清单：
   ```
   python demos/clean_double_blind.py
   ```
2. 确认无误后执行（会自动生成 `.doubleblind_backup_<时间戳>/` 备份）：
   ```
   python demos/clean_double_blind.py --apply
   ```
3. 脚本会复查残留，正常应输出 `复查残留: 0 处`。
4. **注意**：背景图 `url()` 被清空后，页面对应位置可能留白，需手动补一张本地中性背景图。

> 若你的院校不在默认名单里，改 `clean_double_blind.py` 顶部的 `SCHOOL_NAMES` / `SCHOOL_DOMAINS` 即可。

## 四、易漏点（重点看这几条）

- **背景图与 favicon**：清了 `<img>` 但漏了 CSS `url()` 里指向校方服务器的图片，页面仍会外发请求。
- **文档痕迹**：doc 里当作功能描述写下的"集成 XX 学院 Logo"，同样算违规。
- **截图陈旧**：旧截图里带校名，即使现在页面已改，图片不动就是违规。
- **AI 生成的图表/插图**：可能自带水印或单位字样，需肉眼复核。
- **致谢页**：评委致辞、感谢某单位/某老师——**属于违规**，必须删。
- **演示环境的浏览器书签/历史**：巡展时若自动补全出校名，也算现场瑕疵，建议用干净浏览器 + 无痕窗口演示。
